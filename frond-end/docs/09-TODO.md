# Definition of Done (DoD)

Sebuah fitur dianggap selesai apabila:

- Fungsi berjalan sesuai PRD.
- Validasi berhasil.
- Data tersimpan di database.
- UI responsif.
- Tidak ada error kritis.
- Telah diuji pada desktop dan mobile.
- Dokumentasi diperbarui.

---

# Catatan

- Backend dan database tidak diubah tanpa kebutuhan yang jelas.
- Frontend menggunakan React + Vite.
- Semua perubahan mengikuti PRD dan Business Flow.
- Approval DPL dan Supervisor dilakukan melalui email menggunakan token.
- Seluruh aktivitas penting dicatat pada Activity Log.
